Availability of data and materials

The preserved derived resource supporting this study is publicly available in the Stone ClinVar evidence v1.0.0 release (https://github.com/caonimasb13-del/stone-clinvar-evidence/releases/tag/v1.0.0). The derived-resource archive (https://github.com/caonimasb13-del/stone-clinvar-evidence/releases/download/v1.0.0/Stone_ClinVar_derived_resource_LICENSED_PRIVATE.zip) contains21371 saved variant reports with a complete index, the fixed38 evidence overlay,35-gene context, all45 source tables and5 figures, with provenance and source-to-result mappings. These are public-record research outputs, not patient-level outcomes or independent functional truth.

The complete bounded numerical reproduction package is available at https://github.com/caonimasb13-del/stone-clinvar-evidence/releases/download/v1.0.0/Stone_ClinVar_fixed_checkpoint_PORTABLE_PRIVATE.zip. It supplies66 runtime input/reference file identities and matched code. Fifteen selected assertion checkpoints, six third-party dictionaries and nine comparison outputs retain exact saved bytes; seven author-owned protocol/receipt files have documented location-only projections, while the remaining59 runtime files are unchanged. Original source locations, fixed versions and SHA256 identities are recorded in the package. Saved unversioned NCBI URLs must not replace required bytes with latest downloads. Third-party components retain provider-specific terms, attribution and versions.

Code availability

The versioned code is available at https://github.com/caonimasb13-del/stone-clinvar-evidence/tree/v1.0.0 (commit b670a90c2861dc2407e4a489f47c8cfa327a326a); the matching reviewed code-only archive is https://github.com/caonimasb13-del/stone-clinvar-evidence/releases/download/v1.0.0/Stone_ClinVar_CODE_for_PORTABLE_INPUTS_PRIVATE.zip. Use the paired portable input package for the standalone launcher. MIT applies to author-controlled software, and CC BY4.0 to author-original results/documentation, with upstream terms retained.

One uninterrupted fixed-checkpoint run from a new directory on the same Windows host matched nine core JSONL outputs and23 generated source tables. Three manual/documentary tables,19 later SX tables and the saved-report interface are not regenerated by this entry. This differs from full-pipeline, second-host and biological validation. All three published ZIPs were downloaded without credentials and matched complete SHA256 hashes. No DOI has been assigned. Software requires Python3.11 or later and the standard library; Windows was tested, other operating systems were not tested.
