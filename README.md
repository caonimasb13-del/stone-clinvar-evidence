# Stone ClinVar evidence

Preparation repository for source-linked interpretation of ClinVar assertions in a fixed nephrolithiasis gene panel.

## Current contents

The private repository now includes the bounded scientific implementation under analysis/, alongside documentation, citation metadata, input identities and the all93-module/all45-table disposition inventories. Source records, required configuration/dictionary contents, result tables, protected manuscript and internal reviewer ledgers are not uploaded. The code requires separately supplied exact inputs and is not a self-contained public reproduction release or a public data deposit.

The existing manuscript and numerical reproduction module remain separately preserved in the local project. Further derived-data and third-party input exports require their own reviewed file manifest and applicable source-rights decisions. The exported driver uses an explicit external resource directory and omits two internal-ledger hash-only dependencies. In source_deletion.py only the integrity-guard target and its label change from a manuscript to supplied code; seven other algorithm files and the guarded executor retain their bytes. Targeted validation reproduced all seven affected descriptive tables byte for byte and matched all 30 non-metadata summary fields; positive, tamper-negative and outside-write-denial guard fixtures passed; no new complete driver execution or second-host run has been performed. See analysis/README.md. No open software or blanket data licence, repository release or DOI has been assigned in this preparation state.

## Verification scope already recorded locally

The prior staged computation regenerated the fixed census, current dated contrasts, repaired condition scope and selected supporting tables on one Windows host. Nine core JSONL outputs contained 116,505 parsed rows across different, overlapping record units. Their rows matched the preserved reference outputs. Headers and all cells of 23 numerical source tables matched. Three documentary/manual original tables and all 19 later SX tables were preserved, not regenerated in that round.

The full article pipeline, a second-machine run, clinical interpretation performance and independent biological validation were not established by that computation. The final driver was tested in stages with retained input-wiring repairs, not as a single new uninterrupted execution. Existing null findings, unknown states and stopped source families are retained.
