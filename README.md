# Stone ClinVar evidence

Preparation repository for source-linked interpretation of ClinVar assertions in a fixed nephrolithiasis gene panel.

## Current contents

This initialization candidate contains documentation, citation metadata, input identity requirements and a bounded summary of previously completed numerical verification. It does not contain the scientific analysis implementation, source records or required dictionary data. It is not an executable reproduction release or a public data deposit.

The existing manuscript and numerical reproduction module remain separately preserved in the local project. Addition of code, derived source data and third-party inputs requires a reviewed file manifest and applicable source-rights decisions. No open software or blanket data licence, repository release or DOI has been assigned in this preparation state.

## Verification scope already recorded locally

The prior staged computation regenerated the fixed census, current dated contrasts, repaired condition scope and selected supporting tables on one Windows host. Nine core JSONL outputs contained 116,505 parsed rows across different, overlapping record units. Their rows matched the preserved reference outputs. Headers and all cells of 23 numerical source tables matched. Three documentary/manual original tables and all 19 later SX tables were preserved, not regenerated in that round.

The full article pipeline, a second-machine run, clinical interpretation performance and independent biological validation were not established by that computation. The final driver was tested in stages with retained input-wiring repairs, not as a single new uninterrupted execution. Existing null findings, unknown states and stopped source families are retained.

metadata/input_requirements.json lists the 15 exact selected-row checkpoint identities and six dictionary file identities required by the preserved numerical entry. PanelApp, HPO, Gene2Phenotype, ClinVar and ClinGen materials retain their applicable source terms. Public availability of an upstream file does not assign a new licence to it. See THIRD_PARTY_NOTICES.md and PUBLICATION_STATUS.json.
